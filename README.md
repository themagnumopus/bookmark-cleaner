# Bookmark Cleaner

Merge messy bookmark exports from Chrome, Brave and Raindrop into one clean file.

**Live app:** https://bookmark-cleaner.streamlit.app

## What it does
- Upload multiple exports (HTML or CSV) at once
- Removes duplicate links
- Search across all your bookmarks
- Download one clean CSV

Your files are processed in the browser session and never stored.

Built with Python, pandas and Streamlit.
